# Ecosistema Inteligente de Aprendizaje (EIA)

## Descripción

EIA es una plataforma educativa inmersiva que integra:

- ASP.NET Core (.NET 10)
- Unity 3D
- Electron
- Inteligencia Artificial

Su propósito es transformar el aprendizaje en una experiencia interactiva basada en exploración, misiones, competencias y laboratorios virtuales.

---

## Arquitectura

- Backend: ASP.NET Core
- Dominio: Clean Architecture
- Cliente: Electron
- Mundo 3D: Unity
